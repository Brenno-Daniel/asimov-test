# Entrega 1 - Figma para código

## Descrição

Reproduzir as quatro primeiras seções do design do Figma fielmente com código.

### Seções a implementar

- Hero
- Services
- Let's make things happen
- Case Studies

### Requisitos

- O resultado deve ser indistinguível do design
- Espaçamentos, tipografia, cores e responsividade devem ser fielmente reproduzidos
