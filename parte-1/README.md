# Entrega 1 - Figma para código

## Descrição

Reproduzir as quatro primeiras seções do design do Figma fielmente com código.

### Seções implementadas

- **Hero**: Navegação, texto principal, logos de clientes
- **Services**: 6 cards de serviços (SEO, PPC, Social Media, Email, Content, Analytics)
- **Case Studies**: 3 casos de sucesso com resultados
- **CTA**: Seção de contato "Let's make things happen"

### Stack

- Next.js 16 + React 19
- Tailwind CSS 4
- TypeScript
- Lucide React (ícones)

### Como executar

```bash
cd parte-1
pnpm install
pnpm dev
```
